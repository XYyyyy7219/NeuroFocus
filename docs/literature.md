# 九州文学文案 V1.0

## 一天中的文字

首页把正文放在计时区与今日概览之间，保留两个原有区域的阅读顺序。正文字体优先使用已安装的中文宋体，出处沿用界面小字；最多预览两行，完整段落由读者主动展开。深空视图借用现有顶部工具栏的留白，保留单行正文与出处，同一块画布仍可漫游、搜索和进入观测。漆黑画布使用暖灰色文字，专注小窗维持阶段和倒计时。日志、日历和时间轴继续直接展示使用者写下的内容。

每天首次进入某场景时，先筛选有正文、已启用且适用于该场景的条目，再尽量选近期未展示过的文字。首页按本地时段优先匹配类别，05:00–09:59 偏向少年与自然，10:00–16:59 偏向求知与理想，17:00–19:59 偏向哲思与自然，其余时间偏向宁静与悲悯。星图优先求知与史诗，专注优先自然与探索。相同优先级中随机选择。全池均已展示时先轮到最久未出现的条目。当天的手动选择、收藏和使用偏好在重启后保留。

进入一轮专注时按会话选定文案，暂停、微休息、切页和跨午夜沿用当前选择。被用户主动禁用的当轮条目收起。没有合适条目时，页面收回文字占用的空间。不会依据时长、连续天数或任务完成情况指派文案。

## 公共与本地文件

| 文件 | 内容 |
| --- | --- |
| `neurofocus/literary_catalog.json` | 第一卷审核索引 28 条，正文为空且默认禁用。另有 8 则 NeuroFocus 原创示例，各自独立署名。 |
| `data/literature.local.json` | 仅在本机保存用户选摘、额外作品、收藏、启用状态及最近展示记录。写入时先校验整批数据，再用临时文件替换。 |
| `data/settings.json` | 文案总开关、专注时可见性和更新频率。 |
| 手工导出的 `*.nfquotes.json` | 便携文案包，可在另一台电脑上导入；保留各条目的来源和收藏。展示历史跟随本机。 |

本次核对的第一卷 TXT 可按 GB18030 解码，保留空行后共 6,845 行。章节起始行依次为 54、350、2,599、4,365、6,125。三处“历史”标记在第 320、804、6,833 行。软件只在使用者选择文件时进行本地读取，面板预览所选索引的起止行，保存时写入主动选中的文字。不同版本即使行数相同也可能错位，每次选摘均保留核对机会。软件不会记住所选 TXT 的路径。

## 加入第二至第六卷

1. 为要加入的卷核对作者、卷名、章节、节名和一基的起止行，空行计入行号。优先为每个作品、卷和索引分配稳定 ID，例如第二卷使用 `NF-V02-001`，第六卷使用 `NF-V06-001`。
2. 把审核索引写入 UTF-8 JSON 文件。可直接另存下方模板，替换提示字段。尚未核准章节时先完成核对再导入。批量导入可在 `entries` 内增加更多条目。
3. 进入「偏好设置 → 文学文案 → 管理文案库 → 导入 JSON」。导入索引后，该条目可以检索或收藏。使用「填写摘录」保存自己有权使用的内容即可启用；也可以在导入包里提供有权使用的正文并设为启用。
4. 通过作品名、卷号、类别或标签检索。多关键词用空格分隔，例如「九州缥缈录 卷 2」。管理页可单独禁用、恢复和收藏。需要备份时点「导出文案库」。

```json
{
  "version": 1,
  "entries": [
    {
      "id": "NF-V02-001",
      "title": "替换为审核后的索引名称",
      "text": null,
      "categories": ["星辰与求知"],
      "tags": ["探索", "星空"],
      "source": {
        "author": "江南",
        "book": "九州缥缈录",
        "volume": 2,
        "volumeTitle": "替换为经核对的卷名",
        "chapter": "替换为经核对的章节",
        "section": "替换为节名"
      },
      "scenes": ["home", "focus", "starMap"],
      "enabled": false,
      "reviewed": false,
      "favorite": false
    }
  ]
}
```

`lineStart` 与 `lineEnd` 可一同省略，使用 TXT 选段时需补齐为正整数。跨作品导入至少提供作者、作品、稳定 ID、标题、类别与场景。正文最多 6,000 字符，可保存多段和换行。导入器也接受单分类字符串 `category`。类别和标签均可自定义。

同一文件内 ID 重复、同一 ID 来自不同出处、规范化后正文跨条目重复、场景或行号无效，都会取消整批导入。同一 ID 与相同来源可更新本地条目。第一卷内置索引的人工元数据固定，可补正文和调整启用、收藏。若本地文案文件损坏，软件保留原文件并退回公共示例，管理页会显示原因。该功能无需联网。
