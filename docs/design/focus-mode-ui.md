# 专注模式界面

## 从学习任务选择节奏

在表盘左上方并列放置“专注模式”和“学习标签”。比如选择“Deep Work”和“理论力学”，前者决定计时规则，后者决定这段学习的归属。模式选择面板显示名称、中文用途、主要参数及当前选择标记。用户双击或点“使用模式”即可开始使用。侧栏“快捷参数”处理常调数值；完整参数、新建和删除保留在模式面板。

比较过常驻一排模式标签、单行下拉框与按需打开的选择面板。一排标签在 760 像素宽的窗口会与学习科目争夺空间，下拉框很难容纳休息规则。最终采用面板，主界面的占用恒定，自定义方案增多后列表可滚动。[模式选择](../screenshots/focus-engine/mode-selector.png)

## 阶段和反馈

- 倒计时沿用主表盘，学习阶段下方显示整体进度。Pomodoro 显示“第 2 / 4 轮”，短休、长休各有阶段名称和提示音。即使只看数字和文字也能区分。[番茄专注](../screenshots/focus-engine/pomodoro.png) · [番茄短休息](../screenshots/focus-engine/pomodoro-short.png)
- Flowtime 从 00:00 上数，表盘使用固定轮廓并写明正向计时。超过一小时显示时、分、秒。“进入休息”允许手动改写建议值，确认后显示本次自主休息倒计时。[正向计时](../screenshots/focus-engine/flowtime.png) · [自主休息](../screenshots/focus-engine/flowtime-rest.png)
- NeuroFocus 和 Deep Work 共享操作位置，模式色只用于表盘。随机微休息的下一次触发时刻始终隐藏。[随机微休息模式](../screenshots/focus-engine/neurofocus.png) · [连续专注](../screenshots/focus-engine/deep-work.png)
- 新建方案先确定名称和计时方向，再依需要打开微休息、分组、短休息。被关闭的功能显示“关闭”，相关数值随开关隐藏。滚动区域独立于“保存”“取消”。[自定义配置](../screenshots/focus-engine/custom-config.png) · [小窗口](../screenshots/focus-engine/custom-compact.png)
- “学习统计 → 专注模式”可查看今天、近 30 天、全部或自定义日期。表内分别标明活动数、使用轮数、占比和每轮平均，下方说明计算口径。[模式统计](../screenshots/focus-engine/mode-statistics.png)

这些截图来自 Windows 原生界面，使用独立临时数据。颜色沿用浅色和深色主题，正向表盘无需持续动画。
