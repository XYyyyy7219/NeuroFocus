# Focus Engine 2.0 计时与归档

## 同一段时间怎样进入档案

主窗口、托盘和悬浮窗共用 Controller。WindowsClock 读 QueryUnbiasedInterruptTime 计算清醒时间，用本地墙钟给片段标日期。Engine.tick 将两次采样之间的毫秒按最近事件边界切开，产生独立条目。只有 focus 片段进入实际学习时长。微休息是否计入周期只影响倒计时到点的时刻。

每轮开始，Controller 取不可变的 Profile 和组内轮次，在事务中创建会话及参数快照。同一引擎中，倒计时追踪周期已用时间，正向计时直接读累计有效学习时间。相同瞬间到达微休息和周期终点时，周期完成优先。温和提醒只产生通知事件。暂停保存原阶段与剩余量，继续时从新的单调时刻开始累计。

| 模式 | 学习结束条件 | 默认休息 |
| --- | --- | --- |
| NeuroFocus | 周期达到 90 分钟，学习间每 3–5 分钟重新抽取一次微休息 | 微休息 10 秒，周期后 20 分钟 |
| Pomodoro | 满 25 分钟算一轮，四轮一组 | 第 1–3 轮短休息 5 分钟，第 4 轮长休息 20 分钟 |
| Deep Work | 连续学习 60 分钟 | 长休息 15 分钟 |
| Flowtime | 用户主动结束或进入休息 | 对话框预填建议分钟，允许改写 |
| 自定义 | 每个具名方案各有固定 ID，可上数或倒数 | 可组合短、长、随机与自主休息 |

倒计时用户提前休息或结束时保留有效片段，不增加完成轮数。Flowtime 主动进入休息，记录一次明确的学习段结束；直接结束也保存已经学习的时长。自定义正向分组以有实际学习、主动转入休息为推进条件。启用分档建议时以建议预填；关闭时以当前轮的短休或长休分钟预填。

## 边界决策

- 正在运行时选其他方案仅排到下一轮。学习标签则立即生效，原标签的片段先写入。
- 新模式关闭“到点进入休息”后，已完成的专注停在等待界面，直到用户开始或跳过休息。等待期间没有学习或休息时长。原版 NeuroFocus 关闭该选项时延用直接结束的行为。
- 默认手动开始下一轮。启用自动开始时以休息终点为边界处理正常回调的少量迟到。超过 2 秒、系统唤醒或用户手动结束休息时，等待再次开始。
- 所有事件与已累计时长在同一个检查点提交。每个完成事件对应的组进度与活动同时入账。数据库写入失败可以重试同一批次。异常恢复保留最近一次成功提交的数据，通常最多相差一个约 5 秒的常规检查点。
- 偏好中的旧 NeuroFocus 时间参数继续读写原 settings.json；其他方案独立保存。方案改名或删除后，旧会话仍用自己的快照。

## 数据与查询

| 来源 | 保存或读取的内容 |
| --- | --- |
| sessions、session_protocol、study_events | 生命周期、开始时的方案与轮次、暂停毫秒、阶段转换 |
| focus_spans、days | 实际学习片段、标签、每日微休息与长休息、按时完成数 |
| focus_profiles、focus_selected、cycle_cursor | 可编辑方案、下次使用项、每个分组方案的下一轮 |
| rest_days、manual_rest_plan | 短休息和自主休息按自然日的实测毫秒、主动选择的分钟 |
| mode_stats.mode_totals | 查询指定日期内的学习片段，按稳定模式 ID 汇总 |

同日、同会话连续属于同一标签的学习片段形成一项档案活动；跨日或切换到其他标签会形成另一项。使用轮数在选定范围内按有学习片段的会话去重。平均学习时长用范围内毫秒除以这些会话数。模式占比是占使用轮数的比例。组内完成轮数另按明确的完成事件统计。日历、日志、时间轴和星图沿用相同会话与活动键。

旧库首次升级前通过 SQLite backup 生成独立可检验的备份，再增加表与索引。原始学习片段、标签颜色和笔记保留。只有日汇总的记录不会生成推测的开始时刻、休息或模式快照。模式分布把缺少模式 ID 的历史放入“旧版记录”；有旧周期快照的详情仍可展示实际保存的参数。
