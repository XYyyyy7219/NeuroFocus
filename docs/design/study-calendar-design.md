# 三种学习日历方案

| 维度 | 单层年度热图 | 每科一条周历 | 总览热图 + 可筛选的单日详情 |
|---|---|---|---|
| 实用性 | 找高低活动日快 | 适合同时比较少量科目 | 先定位，再回顾当日记录 |
| 视觉 | 最简 | 科目增多后密集 | 主图单色阶，颜色分布留给详情 |
| 交互效率 | 查记录需跳页 | 跨科比较直观 | 悬停速览，点击后逐日前后翻 |
| 信息量 | 日总量 | 科目与日总量 | 总量、比例、周期、休息与时段 |
| 复杂度 | 低 | 中，多网格同步滚动 | 中，批量汇总与详情分层 |
| 性能 | 单个画布 | 成本科目数倍增 | 只画可见列，每次只读选中日明细 |
| 维护 | 简单 | 多组尺寸与标签状态 | 共用 Ring 和原 SQLite 查询口径 |
| 扩展 | 信息承载有限 | 容易添加并排科目 | 详情模块可独立扩充 |
| 桌面适配 | 适合窄窗口 | 纵向空间不足 | 统计页第三个标签，下方详情适应窄窗 |

选择第三种。默认窗口为截至今天的滚动 12 个日历月，自然年视图保留未来格。正时长至 30 分钟为一级，之后依次使用右闭区间至 90、180 分钟。短于一分钟的学习也可见。显示等级没有学习质量含义。

**筛选语义。** 学习毫秒按标签片段累加。微休息、长休息和完成标志只在原来的周期日记录中存在。多选筛选取曾学习过所选标签的周期集合，再按原记录日期计算这些周期的休息与完成数；相同周期仅取一次，跨午夜的休息仍在实际发生日。归档、改名不会产生新科目。不同筛选的周期数因此不能相加。空筛选返回零。没有学习但有休息的日子仍保留详情。

**导航与汇总。** 日均一按范围内截至今日的自然日计，包括今天；日均二仅按正学习时长的日期计。分母为零显示零。范围外格留白，未来格描边，当前选择另加边框。大范围采用裁剪绘制与横向滚动。历史数据的改变由已有计时检查点触发刷新，悬停只查内存。

并排科目周历和逐分钟时间线留待以后：前者随标签数量占用额外空间，后者无法可靠表达旧版仅按日保留的时长。没有引入打卡指标、排行榜或连续天数目标。
