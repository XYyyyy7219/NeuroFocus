# 档案导航与数据流

保留计时、统计和偏好设置入口，新增学习档案将日周时间轴、日志检索和星图放在同一个页面。日历保留原有单日详情，新增打开时间轴的入口。用选定活动键跨页定位，日期、时间段和日志直接读取同一本地数据库。

结束学习时保留原有休息流程，档案提供补记入口。学习断点读取该标签已有日志的「下一步」。资料链接按原文写入 Markdown，导出由用户指定路径。星图使用独立深色背景，其余界面跟随软件主题。没有用户账户或联网图形资源。

快速记录同时也是草稿，约 450 毫秒无输入时写入，关闭编辑器会立即结清输入。深度日志保留 Markdown、代码、公式和资料路径的原始文本。当前未提供 LaTeX 排版、图片附件管理、拖动保存星系位置或任意活动间连线。新增平台能力集中于 Windows 便携版。
