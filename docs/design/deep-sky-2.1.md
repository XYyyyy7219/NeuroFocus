# 深空观测的空间、光照与信息设计

## 活动怎样形成一片星空

档案按既有活动键取数。每个学科占据确定的区域，每个主题有自己的局部原点。主题中的每条有效活动占一个位置。以会话顺序给新成员分配槽位，再根据黄金角、半径增长、缓慢旋转和扁率得到局部椭圆分布。学科 ID 影响朝向与扁率。将子坐标缩放至 0.23 并加到父原点，得到父视图中的同一颗星。两级预览均使用这套变换。

| 方案 | 适用范围与取舍 |
| --- | --- |
| 力导向布局 | 群体能自然分离，加一条记录却可能推动整个星团。持续求解及重启后的复现成本较高。 |
| 固定螺旋加随机散点 | 花纹清晰，少量数据时容易造成已有大量成员的错觉。单个通用点云也难以表达同主题的局部关系。 |
| 分层局部坐标、黄金角与有界半径 | 新会话追加到现有槽位之后。日期演化、标签归档和改名复用完整档案的排位。观察单条记录时可反向沿原坐标进入。选择此方案。 |

空档案显示空状态。一个成员直接显示一颗星，2–10 个成员逐个显示，从 11 个成员起叠加微弱的弥散云气。总览每组最多显示 160 个实际活动样本，数量和时长从全量活动取得。进入主题后所有成员都可访问。筛选可能改变总览的样本集合，保留成员的局部位置一致。主动编辑主题会改变这条活动的归属，观测面板用稳定活动键跟随记录。

## 四个观测距离

| 层级 | 进入条件 | 绘制内容 |
| --- | --- | --- |
| LOD 0 | 绘制时投影半径小于 4 像素 | 复用按标签颜色缓存的点源 |
| LOD 1 | 投影半径 4 至不足 24 像素 | 白热中心、彩色盘面和渐弱光晕；主题层以短弧表示已写日志 |
| LOD 2 | 投影半径至少 24 像素 | 有颗粒和亮纹的光球层及不均匀日冕 |
| LOD 3 | 主动选中记录 | 放大目标，减弱邻星，腾出同屏阅读日志的位置；退出时恢复之前的主题视野 |

投影依据 Qt 绘制变换，高分屏或高分辨率导出会较早触发精细资源。640 像素索引纹理把日冕透明度和表面辐亮度分开存储。离线烘焙把球面坐标投影、变形的多频噪声、邻近对流单元边界与细长亮纹组合。运行时按学科色调映射，最多缓存 12 张高细节着色图。共用底纹通过确定的旋转产生变化。这里选择静态表面，持续模拟粒子与对流的资源开销对回顾学习记录帮助有限。

## 阅读与导航

标签投影至视口后按固定逻辑字号绘制。星群以可见样本的中心为锚点，单记录锚定实际亮点。选中和悬停优先，之后按组规模检查四个邻近位置。画布边界、浮层与既有文字参与避让。密集主题仅在指针附近请求标注。没有合适位置的标签收起，完整名称也可通过悬停或记录列表查看。

进入层级时沿共同祖先转换相机坐标，再用约 240 毫秒缓动对准目标。返回星团可恢复之前的缩放和平移。拖拽、滚轮和低动态选项均可打断过渡。F9 隐藏操作层与标注，F11 切换全屏。退出页面或最小化时停止镜头和逐日演化；专注时间由原有单调时钟继续记录。

恒星面板展示主题、学科、起止时间、实际学习时长、周期策略、周期微休息以及已有日志。“周期”提示这些休息属于整轮，会话含多个活动时不能逐星相加。旧档案缺失的起止信息和策略显示原有兼容说明。现有日志只有五个自由文本字段，可把材料写在其中；此版本未新增附件库、天文参数或小地图。
