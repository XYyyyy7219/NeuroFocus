# 学习活动与原始账本

Store 的 sessions、days、focus_spans 分别记录周期状态、日指标和有效学习片段。Engine 使用单调毫秒，Controller 在暂停、阶段边界、换标签及检查点结算。已有版本缺少配置快照和可靠的休息边界事件，不能从相邻学习块的空白猜测当时为何离开。

档案按周期、本地日期与连续同标签片段合并，活动键取组首片段的复合主键。微休息和暂停仍可在内部片段中查看。跨午夜形成两个可各自写日志的日活动，共用同一周期。没有有效毫秒的周期不会点亮星图。所有有效时长仍在 focus_spans 中计算，三个模块共用同一活动投影。

新增 journal、session_protocol 和 study_events；日志通过外键关联组首片段，删除笔记不会删除时间。建表前对旧库做 SQLite 一致性备份，扩展表在事务内创建。老版仅有日总量的片段保持空起止。旧配置、暂停和事件标作未记录。
